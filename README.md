# my-stardew-wiki

这是一个使用 HTML + CSS 制作的静态网页项目，用来展示类似星露谷物语维基风格的角色资料页。

## 如何查看网页

### 本地查看

1. 用 VS Code 或文件管理器打开项目文件夹。
2. 直接双击 `index.html` 打开浏览器预览。
3. 如果页面样式或图片没有正常显示，建议使用本地静态服务器预览，例如：

```bash
python -m http.server 8000
```

然后在浏览器中访问 `http://localhost:8000/`。

### 在线查看

如果你已经把项目发布到 GitHub Pages，可以直接打开对应的网页链接进行预览。

## GitHub Pages 发布与打开链接

如果你想把这个网页发布到 GitHub 上，并生成一个可直接访问的链接，可以按下面的步骤操作：

1. 在 GitHub 新建一个仓库，把这个项目上传到仓库中。
2. 确认仓库根目录下有 `index.html`、`style.css` 和 `images/` 文件夹。
3. 进入仓库的 `Settings` 页面。
4. 在左侧找到 `Pages` 选项。
5. 在 `Build and deployment` 中选择 `Deploy from a branch`。
6. 选择分支 `main` 或 `master`，目录选择 `/root`。
7. 保存设置后，等待 GitHub 自动部署。
8. 部署完成后，页面会显示一个 GitHub Pages 链接，通常格式类似：

```text
https://你的用户名.github.io/仓库名/
```

9. 打开这个链接，就可以直接查看网页效果。

### 常见注意事项

- `index.html` 必须放在仓库根目录，否则 GitHub Pages 可能无法正确打开页面。
- 如果图片没有显示，通常是图片路径写错，或者文件没有一起上传。
- 每次修改代码后，只要重新提交到 GitHub，Pages 链接会自动更新。
- 如果仓库名里有大写字母、空格或中文，建议尽量使用英文小写仓库名，避免链接不稳定。

### 发布后重新查看页面

1. 打开 GitHub 仓库的 `Settings` > `Pages`，确认页面仍然处于已部署状态。
2. 点击仓库首页或 `Pages` 页面里显示的 GitHub Pages 链接。
3. 如果页面刚更新但内容没有变化，先强制刷新浏览器：`Ctrl + F5`。
4. 如果你刚提交了新代码，等待几秒到几分钟后再重新打开链接。
5. 需要快速检查时，可以直接在浏览器地址栏再次输入同一个 GitHub Pages 链接访问。

## 如何制作

项目的核心文件如下：

- `index.html`：网页结构、目录、内容区、信息框、事件区等。
- `style.css`：背景图、透明效果、目录样式、表格样式、信息框样式等。
- `images/`：网页中使用的背景图、头像、爱心图标、边框图片等资源。

制作或修改时，通常按下面的顺序进行：

1. 先在 `index.html` 中调整内容结构和文字。
2. 再在 `style.css` 中调整布局、颜色、透明度、间距和边框。
3. 如果需要新图片，把图片放进 `images/` 文件夹，并在 HTML 中替换路径。
4. 保存后刷新浏览器查看效果。

## 如何修改

### 修改内容

直接编辑 `index.html`：

- 修改人物姓名、简介、事件说明、表格内容。
- 增加或删除章节标题。
- 调整目录中的锚点链接。

### 修改样式

直接编辑 `style.css`：

- 修改背景图和整体透明度。
- 调整人物信息框、目录栏、表格、标题、爱心事件的样式。
- 修改字号、边距、边框宽度、对齐方式等。

### 修改图片

如果你想替换头像、背景或图标：

1. 将新图片放入 `images/` 文件夹。
2. 在 `index.html` 中把 `src` 改成新图片路径。
3. 如有需要，再在 `style.css` 中调整图片尺寸。

## 修改建议

- 保持 `index.html` 和 `style.css` 的路径关系不变。
- 修改样式后，优先用浏览器刷新检查显示效果。
- 如果页面出现排版异常，先检查图片路径和 CSS 语法是否正确。
